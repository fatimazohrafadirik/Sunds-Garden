Git & GITHUB :

What is GIT ?

Git is a tool that keeps track of changes in your code

What is GITHUB ?

GitHub is a website/platform where you can store and collaborate on Git repositories

The difference between Git and GitHub

Git = the tool on your computer
GitHub = the online place where you can store/share your Git projects

Git is the same as github
Git is an open-source version control system that lets you track changes and manage code locally. It works offline and gives you full control over your repositories. GitHub is a cloud-based platform built around Git.
